# Part 1. Flexbox
For this part I used Flexbox in two places. First, I made the navigation bar — the logo and my name are on the left side, and the menu links are on the right side, all lined up in one row and centered vertically. Second, I made a row of three cards about myself (hometown, school, university). All the cards are in one row, have the same height, and lift up a little when you hover over them. Flexbox made it easy to align everything in a row and control the spacing between items.

# Part 2. Grid System
In this part I used CSS Grid to build two things. First, a small dashboard layout with a header on top, a sidebar on the left showing my study focus, my weekly plan in the main area, and a footer at the bottom — I used grid-template-areas to place everything. Second, I made a photo gallery with 9 images in a 3x3 grid, all the same size, with a caption under each photo and a small zoom effect on hover. Grid was really useful here because it let me control rows and columns at the same time, not just one direction like Flexbox.

# Part 3. Combining Flexbox & Grid
For the last part I put Flexbox and Grid together on one page. I used Grid to split the section into two columns — my projects on the left and my profile/skills info on the right. Then inside each project card, I used Flexbox to line up the image, title, description, and button next to each other. This part helped me understand that Grid is good for the overall page structure, while Flexbox works better for arranging things inside a smaller container like a card.

## Summary
While doing this assignment I learned the difference between Flexbox and Grid. Flexbox was easier for one-direction layouts, like the navbar and the cards. Grid was better for the full page layout and the gallery. In the last task I saw how Flexbox and Grid can work together on the same page. It took me some time to understand how grid-template-areas works, but after testing it a few times it made sense.
